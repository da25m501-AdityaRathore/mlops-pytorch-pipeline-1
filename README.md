# MLOps PyTorch Pipeline

This project demonstrates an end-to-end MLOps workflow for training and deploying a PyTorch image classification model using Docker and Kubernetes.

## Project Structure

mlops-pytorch-pipeline/
├── src/
├── configs/
├── docker/
├── k8s/
├── requirements/
├── tests/
└── .github/


## Features

- PyTorch Image Classification
- Dockerized Training
- Dockerized Inference
- Kubernetes Training Job
- Kubernetes Deployment
- ConfigMaps
- Health Checks
- Horizontal Pod Autoscaler
- GitHub Actions CI

## Dataset

CIFAR-10

## Model

ResNet18
